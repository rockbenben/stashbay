# StashBay 开机自启与管理员权限配置说明

本文档说明 StashBay（FileStash）的开机自启动机制，以及何时需要开启「以管理员身份随 Windows 启动」。

---

## 一、普通权限登录自启

### 适用场景
绝大多数日常场景。日常在资源管理器、浏览器、通讯软件（微信、飞书、QQ 等）之间拖拽文件。

### 实现原理
* 安装版使用当前用户注册表 Run 项，便携版使用当前用户「启动」文件夹中的 StashBay 快捷方式。
* 启动命令带有 `--logon-startup` 参数，登录 Windows 时静默启动并常驻在系统托盘，不弹窗打扰。
* 完全不需要管理员权限（免 UAC 弹窗）。

---

## 二、管理员自启（以管理员权限启动）

### 适用场景
Windows UIPI（用户界面特权隔离）机制规定：**低权限进程无法向高权限进程拖放文件**。
如果您经常以管理员权限运行以下软件，并需要向其拖拽文件，建议开启此功能：
* 以管理员身份运行的终端（CMD / PowerShell / Windows Terminal）
* 以管理员身份运行的开发工具（Visual Studio / VS Code / IDE）
* 特权安装包、解压工具或系统维护软件

### 实现原理
* StashBay **不使用** 注册表 Run 项（因为 Windows 启动时无法直接静默提升权限）。
* StashBay 通过 Windows 任务计划程序（Task Scheduler）注册一个专属于当前用户 SID 的交互式登录任务：
  * **任务名称**：`StashBay.Startup.<User-SID>`
  * **触发器**：当前用户登录系统时
  * **权限等级**：以最高可用权限运行（`HighestAvailable`）
  * **自启延迟**：默认 3 秒（可在设置中配置 0~300 秒，避免开机高峰争抢资源）
* 仅在**首次开启设置时**弹出一次 UAC 授权窗口；授权成功后，后续开机登录均会自动以高权限静默启动，**不再反复弹窗**。

---

## 三、配置与排查

### 如何开启或关闭
1. 打开 StashBay，进入 **设置** → **开机启动**。
2. 勾选 **随 Windows 启动**（开启基础自启）。
3. 如需特权，勾选 **以管理员身份随 Windows 启动**，并在弹出的 UAC 提示框中点击「是」。
4. 取消勾选即可安全注销对应的计划任务、注册表项或启动快捷方式。

### 常见排查
* **开机未自启**：检查任务管理器「启动」选项卡或运行 `taskschd.msc` 查看 `StashBay.Startup.<SID>` 任务状态是否正常。
* **便携版移动了路径**：若移动了 `StashBay.exe` 的所在目录，请从新路径打开程序，在设置中刷新并修复自启，以更新任务中登记的可执行文件路径。
* **杀毒软件拦截**：部分安全软件会拦截添加启动任务，请在安全软件拦截提示中选择「允许」。
