# StashBay

> উইন্ডোগুলির মধ্যে ফাইল স্থানান্তরের একটি হালকা ট্রানজিট শেল্ফ: ফাইল ড্র্যাগ করে রাখুন, ড্র্যাগ করে ব্যবহার করুন — উইন্ডো পাশাপাশি খুলে রাখার কোনো প্রয়োজন নেই।

Windows ডেস্কটপের জন্য একটি হালকা স্থানীয় ফাইল ট্রানজিট স্টেশন। এটি সম্পূর্ণরূপে অফলাইনে কাজ করে, কোনো ক্লাউড আপলোড, নেটওয়ার্ক সংযোগ বা অ্যাকাউন্ট নিবন্ধনের প্রয়োজন নেই। এটি ফাইল সাময়িক জমিয়ে রেখে সাথে সাথে শেষ করার শেল্ফ হিসেবে কিংবা স্ন্যাপশট ব্যাকআপ ও এক-ক্লিকে রিভার্ট করার পূর্ণাঙ্গ ওয়ার্কবেঞ্চ হিসেবে কাজ করে।

## সমর্থিত বিবরণ

| ক্ষেত্র | সমর্থিত স্পেসিফিকেশন |
| :--- | :--- |
| **অপারেটিং সিস্টেম** | Windows 10 (1809+) / Windows 11 (x64 এবং ARM64 নেটিভ সমর্থন) |
| **ডিপেন্ডেন্সি** | অফিশিয়াল ইনস্টলার ও পোর্টেবল সংস্করণে রানটাইম অন্তর্ভুক্ত; স্লিম বিল্ডের জন্য .NET 10 Desktop Runtime প্রয়োজন |
| **সমর্থিত ফাইল** | যেকোনো ফরম্যাটের ফাইল ও বহুস্তরের ফোল্ডার (সম্পূর্ণ আপেক্ষিক ডিরেক্টরি কাঠামো বজায় থাকে) |
| **ইনপুট পদ্ধতি** | ফাইল এক্সপ্লোরার নির্বাচন, ক্লিপবোর্ড ফাইল তালিকা, মাউস নাড়ানোর জেসচার |
| **পুনরুদ্ধারের গন্তব্য** | স্থানীয় ড্রাইভ, নেটওয়ার্ক শেয়ার (UNC / ম্যাপ করা ড্রাইভ), Git রিপোজিটরি |
| **বড় ফাইল সমর্থন** | ২ জিবি-র বেশি একক ফাইল এবং Windows লং পাথ (> ২৬০ অক্ষর) সমর্থন করে |
| **অনুমতি** | ডিফল্টভাবে সাধারণ ব্যবহারকারীর অধিকারে চলে (`%LOCALAPPDATA%\Programs`-এ ইনস্টল হয়); ঐচ্ছিক প্রশাসক অটো-স্টার্ট |
| **ডেটা সংরক্ষণের স্থান** | ডিফল্টভাবে `%LOCALAPPDATA%\StashBay\`-তে সংরক্ষিত হয় (পুরোনো `FileStash` ফোল্ডারের সাথে সম্পূর্ণ সামঞ্জস্যপূর্ণ) |

## দ্রুত শুরু

1. **প্রোগ্রাম ডাউনলোড করুন**: [Releases](https://github.com/rockbenben/stashbay/releases/latest) থেকে ইনস্টলার `StashBay-vx.y.z-setup.exe` (অ্যাডমিন অনুমতির প্রয়োজন নেই) অথবা পোর্টেবল `StashBay-vx.y.z-win-x64.zip` ডাউনলোড করুন।
2. **শেল্ফ চালু করুন**: শর্টকাট <kbd>Win+Alt+S</kbd> টিপুন; মিনি শেল্ফটি বর্তমান স্ক্রিনে মাউস কার্সারের কাছে সাথে সাথে খুলে যাবে।
3. **ফাইল সংরক্ষণ করুন**: ফাইল এক্সপ্লোরারে ফাইল নির্বাচন করে আবার <kbd>Win+Alt+S</kbd> টিপুন (অথবা টেনে শেল্ফে আনুন বা মাউস নাড়ান) — ফাইলগুলো তৎক্ষণাৎ জমা হয়ে যাবে।
4. **এক টানে বের করুন**: শেল্ফের নিচে থাকা `[⤹ মোট X টি আইটেম]` হ্যান্ডেলটি টেনে যেকোনো উইন্ডো বা অ্যাপে ছেড়ে দিন। ফাইল খালি হয়ে গেলে শেল্ফটি নিজে থেকেই মিলিয়ে যাবে।

## মূল বৈশিষ্ট্য

### ন্যূনতম ট্রানজিট শেল্ফ (DropPoint অভিজ্ঞতা)
* **এক টানে বাল্ক এক্সপোর্ট**: সমস্ত ফাইল একসাথে এক্সপ্লোরার, চ্যাট অ্যাপ বা ব্রাউজার ফর্মে ড্র্যাগ করতে নিচের কাউন্টার হ্যান্ডেলটি ব্যবহার করুন।
* **খালি হলে স্বয়ংক্রিয় প্রস্থান**: ফাইল স্থানান্তর সম্পন্ন হলে শেল্ফ থেকে মুছে যায়; শেল্ফ খালি হলে উইন্ডোটি স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যায়।
* **কার্সার অবস্থান অনুসরণ**: গ্লোবাল হটকি মাউস যে মনিটরে রয়েছে সেখানে শেল্ফটি সরাসরি প্রদর্শন করে।
* **মাউস নাড়িয়ে ফাইল জমা**: এক্সপ্লোরারে ফাইল টানার সময় কার্সার সামান্য নাড়ালেই শেল্ফ খুলে যায় এবং ফাইল জমা হয়।
* **ম্যাগনেটিক ভাসমান বল**: স্ক্রিনের প্রান্তে থাকা ছোট বল যাতে ক্লিক করলে শেল্ফ খোলে এবং ছেড়ে দিলে প্রান্তের সাথে আটকে যায়।
* **একাধিক স্বতন্ত্র শেল্ফ**: ট্রে আইকনে ডাবল-ক্লিক করে বা <kbd>Ctrl+Shift+N</kbd> চেপে নতুন সাময়িক শেল্ফ তৈরি করুন; খালি শেল্ফ নিজে থেকেই পরিষ্কার হয়।

### Git শাখা পরিবর্তন সংরক্ষণ ও নিরাপদ পুনরুদ্ধার
* **রিপোজিটরি সচেতনতা**: Git রিপোজিটরির ফাইলের রুট পাথ মনে রাখে; শাখা বদলালে মূল স্থানে এক ক্লিকে পুনরুদ্ধার করার নোটিফিকেশন দেয়।
* **লেখার পূর্বে লক যাচাই**: ফাইল লেখার আগে Windows রিস্টার্ট ম্যানেজারের মাধ্যমে ফাইলটি Office বা IDE-তে খোলা আছে কি না তা পরীক্ষা করে।
* **ওভাররাইটের পূর্বে স্ন্যাপশট**: যেকোনো ফাইল প্রতিস্থাপন করার আগে স্থানীয় ব্লব স্টোরে স্বয়ংক্রিয় ব্যাকআপ তৈরি হয়, যা এক ক্লিকে পূর্বাবস্থায় ফেরানো যায়।
* **হ্যাশ যাচাইয়ে ডুপ্লিকেট পরিহার**: বিষয়বস্তু একই হলে ফাইল নতুন করে লেখা এড়িয়ে যায়, যা মূল পরিবর্তনের সময় রক্ষা করে।

### পূর্ণাঙ্গ ওয়ার্কবেঞ্চ
* **চারটি ভিউ মোড**: ট্রি ভিউ, ফ্ল্যাট তালিকা, সোর্স ফোল্ডার অনুসারে দলবদ্ধকরণ এবং বড় আইকন টাইলস।
* **নমনীয় পুনরুদ্ধার মোড**: মূল অবস্থান, নির্দিষ্ট ফোল্ডার বা নতুন রুট ম্যাপিং; সম্পূর্ণ পাথ, শুধু ফাইলের নাম বা ফ্ল্যাট কাঠামো।
* **দ্বন্দ্বের পূর্বরূপ**: প্রয়োগ করার আগে বিস্তারিত পরিবর্তন পর্যালোচনা করুন: জিজ্ঞাসা, প্রতিস্থাপন, বাদ দেওয়া বা স্বয়ংক্রিয় পুনঃনামকরণ।
* **ব্যাচ অপারেশনের ইতিহাস**: প্রতিটি পুনরুদ্ধারের বিস্তারিত লগ; আংশিক ত্রুটি হলে শুধুমাত্র ব্যর্থ ফাইলগুলো পুনরায় চেষ্টা করা যায়।

### ১৮টি স্থানীয় ভাষা ও থিম
* ১৮টি ভাষার সম্পূর্ণ নেটিভ সমর্থন (স্বয়ংক্রিয় পরীক্ষার মাধ্যমে ১০০% যাচাইকৃত) এবং আরবি (ar-SA)-র জন্য পূর্ণ RTL সমর্থন।
* নিরপেক্ষ গ্রাফাইট টোনের মাধ্যমে Windows ডার্ক ও লাইট মোডের সাথে নিখুঁত সামঞ্জস্য।

## প্রয়োজনীয় কীবোর্ড শর্টকাট

| শর্টকাট | ক্ষেত্র | বিবরণ |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | গ্লোবাল | মিনি শেল্ফ চালু করুন; এক্সপ্লোরারে ফাইল নির্বাচিত থাকলে সরাসরি যোগ করবে |
| <kbd>Win+Alt+W</kbd> | গ্লোবাল | সম্পূর্ণ ওয়ার্কবেঞ্চ চালু করুন |
| <kbd>Win+Alt+V</kbd> | গ্লোবাল | ক্লিপবোর্ডে থাকা ফাইল সরাসরি শেল্ফে জমা করুন |
| <kbd>Ctrl+V</kbd> | উইন্ডোর ভেতরে | সক্রিয় শেল্ফে ক্লিপবোর্ডের ফাইল পেস্ট করুন |
| <kbd>Ctrl+Shift+N</kbd> | উইন্ডোর ভেতরে | একটি নতুন খালি স্বতন্ত্র শেল্ফ তৈরি করুন |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | উইন্ডোর ভেতরে | মিনি শেল্ফ ও পূর্ণ ওয়ার্কবেঞ্চের মধ্যে টগল করুন |
| <kbd>Esc</kbd> | উইন্ডোর ভেতরে | ওয়ার্কবেঞ্চে শেল্ফে সঙ্কুচিত করুন; শেল্ফে ট্রেতে আড়াল করুন |
| <kbd>Delete</kbd> | তালিকা | নির্বাচিত আইটেম শেল্ফ থেকে মুছে ফেলুন |

> [!TIP]
> সমস্ত গ্লোবাল শর্টকাট সেটিংসে গিয়ে পরিবর্তন বা বন্ধ করা যায়। অন্য কোনো প্রোগ্রামের সাথে শর্টকাটের সংঘাত হলে StashBay স্পষ্ট সতর্কতা বার্তা দেখাবে।

## কমান্ড-লাইন ইন্টারফেস (CLI)

`StashBay.exe` স্ক্রিপ্ট ও অটোমেশনের সাথে সংযুক্ত করার জন্য সমৃদ্ধ কমান্ড-লাইন বিকল্প সরবরাহ করে:

| অপশন | বিবরণ |
| :--- | :--- |
| `--add <পাথ...>` | শেল্ফে এক বা একাধিক ফাইল বা ফোল্ডার যোগ করুন |
| `--group <নাম>` | নির্দিষ্ট শেল্ফ নির্দেশ করতে `--add`-এর সাথে ব্যবহার করুন (না থাকলে তৈরি হবে) |
| `--apply-here <ফোল্ডার>` | শেল্ফের ফাইলগুলো নির্দিষ্ট ফোল্ডারে লিখুন |
| `--apply-original` | ফাইলগুলোকে তাদের মূল আপেক্ষিক পাথে পুনরুদ্ধার করুন (Git-এর জন্য উপযুক্ত) |
| `--show` | প্রধান উইন্ডো সামনে এনে প্রদর্শন করুন |
| `--minimized` | সিস্টেম ট্রেতে ছোট করে চালু করুন (Windows অটো-স্টার্টের জন্য) |
| `--quit` | চলমান ইনস্ট্যান্স নিরাপদে বন্ধ করুন |
| `--unregister-shell` | রাইট-ক্লিক মেনু, সেন্ড-টু শর্টকাট ও অটো-স্টার্ট সরান |

## পরিচিত সীমাবদ্ধতা

* **শুধুমাত্র Windows-এর জন্য**: Windows Shell, DWM এবং নিরাপত্তা নিয়ন্ত্রণের সাথে গভীরভাবে সংহত; অন্যান্য OS সংস্করণের পরিকল্পনা নেই।
* **লিংকের বদলে স্ন্যাপশট কপি**: ফাইল যোগ করার সময় বিষয়বস্তুর অনুলিপি তৈরি হয়; পরে মূল ফাইল পরিবর্তন করলেও শেল্ফে কোনো প্রভাব পড়ে না।
* **একক ইনস্ট্যান্স মেকানিজম**: পুনরায় চালু করলে প্যারামিটারগুলো ব্যাকগ্রাউন্ড ট্রেতে চলমান অ্যাপে সরাসরি পাঠানো হয়।
* **প্রশাসক অটো-স্টার্ট দ্রষ্টব্য**: ডিফল্টভাবে সাধারণ অধিকারে চলে। প্রশাসক উইন্ডোতে ফাইল ড্র্যাগ করার প্রয়োজন হলে সেটিংসে অ্যাডমিন অটো-স্টার্ট চালু করে UAC অনুমোদন করুন। [অটো-স্টার্ট সেটআপ নির্দেশিকা](../admin-startup.md)।
