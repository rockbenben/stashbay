# StashBay

> Компактная полка для перемещения файлов между окнами: перетащите внутрь, перетащите наружу и готово — больше не нужно держать окна рядом.

Легковесная локальная станция транзита файлов для рабочего стола Windows. Работает полностью локально, без отправки данных в облако, без сетевых запросов и без регистрации аккаунта. Служит как быстрой промежуточной полкой по принципу «использовал и закрыл», так и полноценным рабочим столом для файлов с поддержкой веток Git, резервным копированием снимков и отменой действий в один клик.

## Поддерживаемые возможности

| Параметр | Характеристики |
| :--- | :--- |
| **Операционная система** | Windows 10 (1809+) / Windows 11 (нативная поддержка x64 и ARM64) |
| **Зависимости** | Официальный инсталлятор и портативная версия содержат встроенную среду выполнения; компактные сборки требуют .NET 10 Desktop Runtime |
| **Поддерживаемые данные** | Файлы любых форматов и вложенные папки (полное сохранение относительной структуры каталогов) |
| **Источники добавления** | Выделение в Проводнике Windows, список файлов в буфере обмена, жест встряхивания мыши |
| **Места восстановления** | Локальные диски, сетевые папки (UNC / подключенные диски), репозитории Git |
| **Большие файлы** | Поддержка отдельных файлов размером более 2 ГБ и длинных путей Windows (> 260 символов) |
| **Права доступа** | По умолчанию запускается с обычными правами пользователя (установка в `%LOCALAPPDATA%\Programs`); опциональный автозапуск от администратора |
| **Хранилище данных** | По умолчанию сохраняется в `%LOCALAPPDATA%\StashBay\` (полная совместимость со старой папкой `FileStash`) |

## Быстрый старт

1. **Скачивание**: Загрузите инсталлятор `StashBay-vx.y.z-setup.exe` (не требует прав администратора) или портативный архив `StashBay-vx.y.z-win-x64.zip` со страницы [Releases](https://github.com/rockbenben/stashbay/releases/latest).
2. **Вызов полки**: Нажмите комбинацию клавиш <kbd>Win+Alt+S</kbd> — мини-полка сразу откроется рядом с курсором мыши на активном экране.
3. **Добавление файлов**: Выделите файлы в Проводнике и снова нажмите <kbd>Win+Alt+S</kbd> (или перетащите их на полку, или покачайте мышь из стороны в сторону) — выбранные файлы мгновенно окажутся на полке.
4. **Перетаскивание одним движением**: Потяните за нижнюю ручку `[⤹ Всего X элементов]`, чтобы одним жестом перенести все файлы в целевое окно или мессенджер. Когда полка опустеет, она плавно закроется сама.

## Ключевые возможности

### Минималистичная полка для переноса (опыт DropPoint)
* **Пакетный экспорт в одно действие**: Потяните за ручку со счётчиком, чтобы перетащить всю пачку файлов в Проводник, мессенджеры или веб-формы за один раз.
* **Автоматическое скрытие**: Успешно перенесённые файлы сразу исчезают с полки; когда на ней ничего не остаётся, окно плавно растворяется.
* **Появление у курсора**: Глобальная горячая клавиша определяет, на каком мониторе находится мышь, и разворачивает полку прямо там.
* **Встряхивание для добавления**: При перетаскивании файлов в Проводнике слегка покачайте мышь из стороны в сторону, чтобы открыть полку и сложить файлы на месте.
* **Магнитный плавающий шар**: Небольшой виджет у края экрана, который открывается по клику или короткому потягиванию и примагничивается к границе экрана.
* **Несколько независимых полок**: Двойной клик по значку в трее или нажатие <kbd>Ctrl+Shift+N</kbd> создаёт новую временную полку; пустые временные полки убираются автоматически.

### Сохранение веток Git и безопасное восстановление
* **Распознавание репозиториев**: Файлы из Git-репозиториев сохраняют путь относительно корня; при переключении веток всплывает подсказка с восстановлением на место в один клик.
* **Проверка блокировок перед записью**: Обращается к Диспетчеру перезапуска Windows, чтобы выявить занятые файлы (в Word, Excel или IDE) до записи и предотвратить повреждения.
* **Безопасные снимки перед перезаписью**: Перед заменой файлов автоматически создаётся резервная копия в локальном хранилище Blob с возможностью отката в один клик.
* **Пропуск идентичных файлов по хешу**: Если содержимое совпадает побайтово, запись пропускается, сохраняя исходное время изменения и исключая лишние пересборки проекта.

### Полнофункциональный рабочий стол
* **Четыре режима отображения**: Древовидная структура, плоский список, группировка по исходным папкам и крупные значки с сохранением выбранного вида.
* **Гибкие сценарии восстановления**: Исходное расположение, указанная папка или сопоставление новому корню; структура с полным относительным путем, только имя или всё в одну папку.
* **Предварительный просмотр конфликтов**: Детальный просмотр запланированных действий перед записью: Спрашивать, Перезаписать, Пропустить или Переименовать.
* **История пакетных операций**: Подробный журнал по каждому применению; в случае частичного сбоя можно повторить запись только для неудачных файлов.

### 18 встроенных языков и темы оформления
* Нативная поддержка 18 языков (100% совпадение ключей проверено тестами) и полная зеркализация интерфейса RTL для арабского языка (ar-SA).
* Идеальная адаптация к темной и светлой темам Windows в спокойных графитовых тонах.

## Популярные горячие клавиши

| Сочетание | Область | Описание |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | Глобально | Вызов мини-полки; если в Проводнике выделены файлы, сразу добавляет их |
| <kbd>Win+Alt+W</kbd> | Глобально | Вызов полного рабочего стола |
| <kbd>Win+Alt+V</kbd> | Глобально | Добавление на полку файлов из буфера обмена |
| <kbd>Ctrl+V</kbd> | В окне | Вставка файлов из буфера в активную полку |
| <kbd>Ctrl+Shift+N</kbd> | В окне | Создание новой пустой независимой полки |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | В окне | Переключение между мини-полкой и полным рабочим столом |
| <kbd>Esc</kbd> | В окне | В режиме рабочего стола сворачивает в полку; в режиме полки прячет в трей |
| <kbd>Delete</kbd> | Список | Удаление выделенных элементов из полки |

> [!TIP]
> Все глобальные горячие клавиши можно перенастроить или отключить в настройках. При конфликте с другой программой StashBay выдаст понятное предупреждение.

## Параметры командной строки (CLI)

`StashBay.exe` предоставляет удобный интерфейс командной строки для запуска через скрипты и автоматизации:

| Параметр | Описание |
| :--- | :--- |
| `--add <пути...>` | Добавить один или несколько файлов/папок на полку |
| `--group <имя>` | Указывает целевую группу вместе с `--add` (создаётся, если отсутствует) |
| `--apply-here <папка>` | Восстановить файлы из полки в указанную папку |
| `--apply-original` | Восстановить файлы по исходным относительным путям (для Git) |
| `--show` | Отобразить и вывести на передний план главное окно |
| `--minimized` | Запустить свёрнутым в трей (для автозагрузки системы) |
| `--quit` | Безопасно завершить работающий экземпляр |
| `--unregister-shell` | Удалить пункты контекстного меню, ярлык «Отправить» и автозапуск |

## Известные ограничения

* **Только для Windows**: Программа глубоко интегрирована с оболочкой Windows Shell, композицией DWM и правами доступа; версий для других ОС не планируется.
* **Снимки вместо ссылок**: При добавлении создаётся локальный снимок содержимого; последующие изменения оригинальных файлов не влияют на полку.
* **Один экземпляр**: Повторный запуск передаёт параметры уже работающему в трее процессу, не плодя фоновые дубликаты.
* **Автозапуск от имени администратора**: По умолчанию работает с обычными правами. Если требуется перетаскивать файлы в окна, запущенные от администратора, включите автозапуск администратора в настройках и подтвердите запрос UAC. [Руководство по автозапуску](../admin-startup.md).
