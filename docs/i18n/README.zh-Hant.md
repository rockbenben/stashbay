Windows 桌面端輕量檔案中轉站。全部本機執行，零上傳、不聯網、免註冊。既是用完即走的極簡中轉架，也是支援改動備份與一鍵還原的完整檔案工作台。

---

## 支援範圍

| 維度 | 支援規格 |
| :--- | :--- |
| **作業系統** | Windows 10 (1809+) / Windows 11（原生支援 x64 與 ARM64） |
| **執行依賴** | 官方安裝版與免安裝版均內建執行階段，解壓/按兩下即用；精簡版需 .NET 10 桌面執行階段 |
| **暫存對象** | 任意格式檔案、多層資料夾（完整保留相對目錄層級） |
| **輸入來源** | 檔案總管多選、剪貼簿檔案清單、滑鼠晃動自動入箱 |
| **寫回目標** | 本機硬碟、網路共用路徑（UNC / 對應磁碟機代號）、Git 程式碼儲存庫 |
| **大檔案支援** | 支援單個 >2GB 大檔案，支援 Windows 長路徑（>260 字元） |
| **權限機制** | 預設一般使用者權限執行（安裝在 `%LOCALAPPDATA%\Programs` 免提權）；可選註冊管理員自啟 |
| **資料位置** | 預設儲存在 `%LOCALAPPDATA%\StashBay\`，自動相容舊版 `FileStash` 目錄 |

## 快速開始

1. **取得程式**：從 [Releases](https://github.com/rockbenben/048-stashbay/releases/latest) 下載安裝包 `StashBay-vx.y.z-setup.exe`（免管理員權限）或免安裝綠色包 `StashBay-vx.y.z-win-x64.zip`。
2. **喚出擱架**：按下快捷鍵 <kbd>Win+Alt+S</kbd>，迷你擱架即刻在當前滑鼠游標所在螢幕展開。
3. **放入檔案**：在檔案總管中選取檔案，再次按下 <kbd>Win+Alt+S</kbd>（或拖入擱架、或晃動滑鼠），選取的檔案立刻入箱。
4. **一鍵拖出**：拖住擱架底部的 `[⤹ 共 X 項]` 控點，一次拖曳即可將所有檔案拖入目標視窗或通訊軟體。檔案全部移出後擱架自動淡出關閉。

## 核心特性

### 極簡中轉擱架（DropPoint 體驗）
* **一鍵批次匯出**：拖曳底部計數把手，單個手勢將整箱檔案一次性拖至檔案總管、通訊軟體或瀏覽器表單。
* **拖出即清空**：檔案成功落入目標後自動從架上移除；架空後視窗平滑淡出，無需手動整理。
* **跟隨游標喚醒**：全域快速鍵呼出時自動定位至當前滑鼠所在顯示器，無需跨螢幕尋找視窗。
* **晃動滑鼠入架**：拖選檔案時輕晃游標即可原地呼出擱架並自動暫存。
* **邊緣磁吸懸浮球**：桌面貼邊小球，按一下或輕拖即展開，放開自動吸附螢幕邊緣。
* **多執行個體獨立擱架**：按兩下系統匣圖示或在視窗內按 <kbd>Ctrl+Shift+N</kbd> 即可新增獨立暫存箱；暫存箱清空後自動清理，避免堆積。

### Git 分支改動託管與安全寫回
* **儲存庫智慧感知**：暫存檔案歸屬 Git 儲存庫時，自動解析儲存庫根目錄；切換分支時快顯提醒，支援一鍵寫回原位。
* **寫前佔用檢測**：寫回前自動呼叫 Windows 重啟管理員檢測檔案佔用（如 Word、Excel、IDE），防止寫入中斷損壞。
* **覆寫安全備份**：任何檔案被覆寫前均自動快照備份至本機 Blob 內容定址庫，支援一鍵復原。
* **內容雜湊比對**：內容一致時自動跳過寫入，保留原始修改時間，避免觸發無謂的專案重新建置或熱重載。

### 完整工作台
* **多檢視切換**：提供樹狀層級、扁平清單、依來源目錄分組及大圖示平鋪四種檢視，狀態記憶持久化。
* **彈性落地模式**：支援依原位置寫回、指定目標目錄或對應新根路徑；目錄結構可選完整保留、僅檔案名稱或全部拍平。
* **衝突預防預覽**：寫入前提供明細預覽，支援詢問、覆寫、略過、自動重新命名四種衝突解決策略。
* **批次操作歷史**：每次落地均記錄詳細執行日誌與結果，部分失敗時僅需針對失敗項重試。

### 原生多語言與無縫適配
* 內建 18 門語言原生支援，各語言詞條 100% 逐鍵對齊；完整支援阿拉伯語（ar-SA）RTL 介面鏡像排版。
* 完美適配 Windows 深色與淺色模式，語言與主題均可跟隨系統自動切換。

## 常用快捷鍵

| 快捷鍵 | 作用範圍 | 功能說明 |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | 全域 | 喚出迷你擱架；前景為檔案總管且有選取檔案時直接入架 |
| <kbd>Win+Alt+W</kbd> | 全域 | 喚出完整工作台 |
| <kbd>Win+Alt+V</kbd> | 全域 | 將剪貼簿中的檔案直接加入暫存 |
| <kbd>Ctrl+V</kbd> | 視窗內 | 貼上剪貼簿檔案至當前暫存箱 |
| <kbd>Ctrl+Shift+N</kbd> | 視窗內 | 新增一個獨立的空暫存箱 |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | 視窗內 | 在迷你擱架與完整工作台之間無縫切換 |
| <kbd>Esc</kbd> | 視窗内 | 工作台模式下縮回擱架；擱架模式下隱藏至系統匣 |
| <kbd>Delete</kbd> | 清單 | 移出選取的暫存項目 |

> [!TIP]
> 全域快速鍵均可在設定中自訂修改或單獨停用；若按鍵被系統其他程式佔用，軟體會明確提示衝突而非無聲失效。

## 命令列參數（CLI）

`StashBay.exe` 提供豐富的命令列介面，便於與外部啟動器、系統指令碼或自動化工作流程整合：

| 命令參數 | 功能說明 |
| :--- | :--- |
| `--add <路徑...>` | 將指定的一個或多個檔案/資料夾加入暫存箱 |
| `--group <分組名稱>` | 配合 `--add` 使用，指定目標暫存箱（不存在則自動建立） |
| `--apply-here <目錄>` | 將當前暫存箱內容寫回至指定目錄 |
| `--apply-original` | 依原始相對路徑原路寫回（適合 Git 分支復原） |
| `--show` | 喚出並顯示主視窗介面 |
| `--minimized` | 最小化無訊息啟動至系統匣（用於系統自啟） |
| `--quit` | 安全結束正在執行的執行個體 |
| `--unregister-shell` | 清除右鍵功能表、傳送到捷徑及開機自啟項目 |

## 已知限制

* **平台專屬**：深度整合 Windows Shell、DWM 混合排版與 Windows 存取控制，僅支援 Windows 系統。
* **資料快照機制**：檔案暫存時立即建立內容快照複本而非符號連結；後續修改來源檔案不會改變暫存箱內容，防誤改誤刪。
* **單一執行個體機制**：重複執行會將參數自動轉發至已執行的系統匣主處理程序，不會產生多餘的孤兒處理程序。
* **管理員自啟說明**：開機自啟預設以一般使用者權限執行；若需常駐處理管理員視窗拖曳，可在設定中勾選管理員自啟並在註冊時透過 UAC 授權。[自啟配置與排查說明](../admin-startup.md)。
