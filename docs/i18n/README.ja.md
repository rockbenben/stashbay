# StashBay

> ウィンドウ間でのファイル移動をスムーズにする極小中継シェルフ：ドラッグして一時退避、ドラッグして使い切る、並べてウィンドウを開く必要はありません。

Windows 向けの軽量ローカルファイル中継ステーション。すべてローカル環境で動作し、クラウドへのアップロードや外部通信、アカウント登録は一切不要です。使い捨て感覚で使える極小シェルフとしても、スナップショットバックアップとワンクリック取り消しを備えた本格的なファイルワークベンチとしても活躍します。

---

## 対応範囲

| 項目 | 対応仕様 |
| :--- | :--- |
| **OS** | Windows 10 (1809+) / Windows 11（x64 および ARM64 にネイティブ対応） |
| **動作環境** | 公式インストーラー版およびポータブル版はランタイム内蔵（展開・ダブルクリックですぐ起動）。軽量版には .NET 10 Desktop Runtime が必要です |
| **対象データ** | あらゆる形式のファイル、複数階層のフォルダー（相対パス構造を完全に保持） |
| **取り込み方法** | エクスプローラーの複数選択、クリップボードのファイル一覧、マウスのシェイク検知 |
| **書き戻し先** | ローカルディスク、ネットワーク共有（UNC / 割り当てドライブ）、Git リポジトリ |
| **大容量ファイル** | 2GB 超の単一ファイル、Windows ロングパス（260 文字超）に対応 |
| **権限仕様** | 標準ユーザー権限で動作（`%LOCALAPPDATA%\Programs` にインストール、UAC 昇格不要）。管理権限での自動起動も選択可能 |
| **保存先** | デフォルトで `%LOCALAPPDATA%\StashBay\` に保存（旧 `FileStash` フォルダーとも自動互換） |

## クイックスタート

1. **プログラムの入手**：[Releases](https://github.com/rockbenben/048-stashbay/releases/latest) からインストーラー `StashBay-vx.y.z-setup.exe`（管理者権限不要）またはポータブル版 `StashBay-vx.y.z-win-x64.zip` をダウンロードします。
2. **シェルフの呼び出し**：ショートカットキー <kbd>Win+Alt+S</kbd> を押すと、マウスポインターがある画面にミニシェルフが即座に開きます。
3. **ファイルの一時保管**：エクスプローラーでファイルを選択し、再度 <kbd>Win+Alt+S</kbd> を押す（またはシェルフへドラッグ、またはマウスを小刻みに振る）と、選択ファイルがシェルフに収まります。
4. **まとめてドラッグアウト**：シェルフ下部の `[⤹ 合計 X 件]` ハンドルをドラッグすると、1 回のマウス操作ですべてのファイルを目的のウィンドウやチャットアプリへ書き出せます。ファイルが空になると自動でフェードアウトして閉じます。

## 主な機能

### ミニマル中継シェルフ（DropPoint 体験）
* **ワンアクションの一括書き出し**：下部の件数ハンドルをドラッグするだけで、シェルフ内の全ファイルをエクスプローラーやチャットツール、ブラウザのフォームへ一括転送できます。
* **空になると自動非表示**：ファイルが正常にドロップされるとシェルフから自動で除外され、全ファイルが取り出されるとウィンドウが滑らかに非表示になります。
* **カーソル位置に追随して展開**：グローバルホットキーで呼び出すと、現在マウスがあるモニターへ瞬時に移動して表示されます。
* **マウスシェイクで取り込み**：エクスプローラーでファイルをドラッグ中にカーソルを素早く左右に振ると、その場でシェルフが展開して自動保存されます。
* **画面端に吸着するフロートボール**：画面端に常駐する小さなウィジェット。クリックまたは短いドラッグでシェルフが開き、離すと画面端にマグネット吸着します。
* **複数シェルフの独立管理**：トレイアイコンのダブルクリックまたは <kbd>Ctrl+Shift+N</kbd> で独立した一時シェルフを新規作成。空になった一時シェルフは自動で片付けられます。

### Git ブランチ変更の退避と安全な復元
* **リポジトリ自動認識**：保管したファイルが Git リポジトリ内にある場合、ルートディレクトリを自動特定。ブランチを切り替えると通知が表示され、元の場所へワンクリックで書き戻せます。
* **書き込み前のロック検知**：書き戻し前に Windows 再起動マネージャーを呼び出し、Office ソフトや IDE によるファイルロックを検知して不完全な上書きを防ぎます。
* **上書き前の安全スナップショット**：既存ファイルの上書き前に、コンテンツ識別型ローカル Blob ストアへ自動バックアップ。いつでもワンクリックで取り消し可能です。
* **ハッシュ照合による無駄な書き込み防止**：内容が一致している場合は書き込みをスキップして元の更新日時を保持し、ビルドやホットリロードの無駄なトリガーを防ぎます。

### フル機能ワークベンチ
* **多彩な表示モード**：ツリー階層、フラットリスト、ソース別フォルダー表示、大きなアイコン表示の 4 種類を切り替え可能。表示状態は記憶されます。
* **柔軟な復元モード**：元のパスへの復元、指定フォルダーへの出力、別ルートへのマッピングに対応。階層構造の維持やフラット展開も選択できます。
* **競合の事前プレビュー**：書き込み前に詳細な変更内容をプレビュー確認可能。「確認」「上書き」「スキップ」「自動リネーム」の 4 つの方針を選べます。
* **バッチ履歴ログ**：復元処理ごとに詳細なログと結果を記録。一部が失敗した場合でも、失敗項目のみを選んで再試行できます。

### ネイティブ多言語対応とテーマ
* 18 言語のネイティブ対応（テストにより全キー 100% 一致を保証）。アラビア語（ar-SA）の RTL レイアウト反転も完全サポート。
* Windows のダークモードおよびライトモードに美しく馴染むニュートラルグラファイト配色を採用。

## よく使うショートカットキー

| ショートカット | 有効範囲 | 説明 |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | グローバル | ミニシェルフを呼び出し。エクスプローラーでファイル選択中なら即座に保管 |
| <kbd>Win+Alt+W</kbd> | グローバル | フル機能ワークベンチを呼び出し |
| <kbd>Win+Alt+V</kbd> | グローバル | クリップボード内のファイルを直接シェルフに追加 |
| <kbd>Ctrl+V</kbd> | ウィンドウ内 | クリップボード内のファイルをアクティブなシェルフに貼り付け |
| <kbd>Ctrl+Shift+N</kbd> | ウィンドウ内 | 独立した空の一時シェルフを新規作成 |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | ウィンドウ内 | ミニシェルフとフルワークベンチをワンキーで切り替え |
| <kbd>Esc</kbd> | ウィンドウ内 | ワークベンチ時はシェルフに縮小、シェルフ時はタスクトレイに格納 |
| <kbd>Delete</kbd> | 一覧 | 選択中の保管項目を削除 |

> [!TIP]
> グローバルホットキーは設定画面で自由に変更または無効化できます。他のソフトと重複した場合は、無言で失敗せず明示的に警告します。

## コマンドライン引数（CLI）

`StashBay.exe` は豊富な CLI パラメーターを備えており、外部ランチャーや自動化スクリプトとの連携も容易です：

| オプション | 説明 |
| :--- | :--- |
| `--add <パス...>` | 指定したファイルまたはフォルダーをシェルフに追加 |
| `--group <グループ名>` | `--add` と組み合わせて対象グループを指定（未作成なら自動生成） |
| `--apply-here <ディレクトリ>` | シェルフ内のファイルを指定フォルダーへ書き戻し |
| `--apply-original` | 相対パスを維持したまま元の場所へ書き戻し（Git 復元に最適） |
| `--show` | メインウィンドウを呼び出して表示 |
| `--minimized` | タスクトレイへ最小化状態でサイレント起動（自動起動用） |
| `--quit` | 実行中のインスタンスを安全に終了 |
| `--unregister-shell` | 右クリックメニュー、送るメニュー、自動起動の登録をすべて解除 |

## 既知の制限事項

* **Windows 専用設計**：Windows Shell、DWM 合成、アクセスコントロールと深く統合されているため、Windows 以外の OS には対応していません。
* **スナップショット方式**：保管時にファイルの実体を複製するため、後から元のファイルを変更しても保管内容は影響を受けません。
* **単一インスタンス管理**：多重起動時は自動で実行中のトレイプロセスにパラメーターを渡し、不要な多重プロセスを防ぎます。
* **管理者自動起動の注意点**：標準では一般ユーザー権限で常駐します。管理者権限のウィンドウへファイルをドラッグする必要がある場合は、設定で管理者自動起動を有効にし、登録時に UAC 昇格を許可してください。[自動起動設定ガイド](../admin-startup.md)。
