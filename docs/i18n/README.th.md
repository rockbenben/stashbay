# StashBay

> เชลฟ์ขนาดเล็กสำหรับพักและย้ายไฟล์ระหว่างหน้าต่าง: ลากมาวางไว้ แล้วลากออกไปใช้ — ไม่จำเป็นต้องเปิดหน้าต่างเทียบกันสองข้างอีกต่อไป

สถานีพักและส่งต่อไฟล์แบบโลคอลสำหรับเดสก์ท็อป Windows ทำงานแบบออฟไลน์ทั้งหมด ไม่มีการอัปโหลดไฟล์ขึ้นคลาวด์ ไม่เชื่อมต่อเครือข่าย และไม่ต้องลงทะเบียนบัญชี ใช้งานได้ทั้งแบบเชลฟ์ชั่วคราวที่ใช้เสร็จก็ปิดไป หรือเป็นโต๊ะทำงานจัดการไฟล์เต็มรูปแบบพร้อมการสำรองข้อมูลสแนปช็อตและเลิกทำได้ในคลิกเดียว

---

## ขอบเขตการรองรับ

| ด้าน | ข้อมูลจำเพาะที่รองรับ |
| :--- | :--- |
| **ระบบปฏิบัติการ** | Windows 10 (1809+) / Windows 11 (รองรับทั้ง x64 และ ARM64) |
| **การทำงาน** | เวอร์ชันติดตั้งและพกพามี Runtime มาในตัว; รุ่นกะทัดรัดต้องใช้ .NET 10 Desktop Runtime |
| **ไฟล์ที่รองรับ** | ไฟล์ทุกประเภทและโฟลเดอร์หลายชั้น (คงโครงสร้างโฟลเดอร์เดิมไว้ครบถ้วน) |
| **วิธีนำเข้า** | เลือกไฟล์ใน File Explorer, รายการไฟล์ในคลิปบอร์ด, เขย่าเมาส์ขณะลากไฟล์ |
| **ปลายทางการเขียนคืน** | ดิสก์ในเครื่อง, โฟลเดอร์แชร์ในเครือข่าย (UNC / ไดรฟ์ที่แมป), Git Repository |
| **ไฟล์ขนาดใหญ่** | รองรับไฟล์เดี่ยวขนาดใหญ่กว่า 2GB และรองรับพาธยาวของ Windows (> 260 ตัวอักษร) |
| **สิทธิ์การใช้งาน** | ทำงานด้วยสิทธิ์ผู้ใช้ทั่วไปตามค่าเริ่มต้น (ติดตั้งใน `%LOCALAPPDATA%\Programs`); เลือกเริ่มระบบแบบผู้ดูแลระบบได้ |
| **ตำแหน่งข้อมูล** | บันทึกไว้ใน `%LOCALAPPDATA%\StashBay\` ตามค่าเริ่มต้น (เข้ากันได้กับโฟลเดอร์ `FileStash` เดิม) |

## เริ่มต้นใช้งาน

1. **ดาวน์โหลดโปรแกรม**: ดาวน์โหลดตัวติดตั้ง `StashBay-vx.y.z-setup.exe` (ไม่ต้องใช้สิทธิ์แอดมิน) หรือแบบพกพา `StashBay-vx.y.z-win-x64.zip` จาก [Releases](https://github.com/rockbenben/048-stashbay/releases/latest)
2. **เรียกเชลฟ์**: กดปุ่มลัด <kbd>Win+Alt+S</kbd> เชลฟ์ขนาดกะทัดรัดจะเปิดขึ้นใกล้เคอร์เซอร์เมาส์บนหน้าจอที่ใช้งานอยู่ทันที
3. **วางไฟล์ลงเชลฟ์**: เลือกไฟล์ใน File Explorer แล้วกด <kbd>Win+Alt+S</kbd> อีกครั้ง (หรือลากไฟล์ใส่เชลฟ์ หรือเขย่าเมาส์) ไฟล์ที่เลือกจะถูกเก็บลงเชลฟ์ทันที
4. **ลากออกไปใช้ในคลิกเดียว**: จับที่แถบ `[⤹ รวม X รายการ]` ด้านล่าง แล้วลากไฟล์ทั้งหมดไปยังหน้าต่างปลายทางหรือแอปแชท เมื่อไฟล์ถูกนำออกหมด เชลฟ์จะค่อยๆ จางและปิดตัวเองโดยอัตโนมัติ

## ฟีเจอร์หลัก

### เชลฟ์พักไฟล์ขนาดกะทัดรัด (ประสบการณ์แบบ DropPoint)
* **ลากออกเป็นชุดในครั้งเดียว**: ลากแถบนับจำนวนด้านล่างเพื่อส่งไฟล์ทั้งหมดไปยัง File Explorer, แอปแชท หรือฟอร์มบนเว็บในท่าทางเดียว
* **ปิดอัตโนมัติเมื่อว่างเปล่า**: ไฟล์ที่นำออกสำเร็จจะถูกลบออกจากเชลฟ์ทันที และเมื่อไม่มีไฟล์เหลือ หน้าต่างจะค่อยๆ จางหายไปเอง
* **เปิดขึ้นตามตำแหน่งเคอร์เซอร์**: ปุ่มลัดส่วนกลางจะตรวจจับหน้าจอที่เมาส์อยู่และเปิดเชลฟ์ขึ้นมา ณ จุดนั้นโดยตรง
* **เขย่าเมาส์เพื่อเก็บไฟล์**: ขณะลากไฟล์ใน File Explorer ให้เขย่าเมาส์เบาๆ เพื่อเรียกเชลฟ์และบันทึกไฟล์ในตำแหน่งเดิม
* **ลูกบอลลอยดูดติดขอบจอ**: วิดเจ็ตขนาดเล็กที่ขอบจอ คลิกหรือลากสั้นๆ เพื่อขยายออก และจะดูดติดขอบจอทันทีเมื่อปล่อย
* **แยกเชลฟ์อิสระหลายชุด**: ดับเบิลคลิกที่ไอคอนถาดระบบหรือกด <kbd>Ctrl+Shift+N</kbd> เพื่อเปิดเชลฟ์ชั่วคราวใหม่ เชลฟ์ที่ว่างเปล่าจะถูกล้างทิ้งโดยอัตโนมัติ

### สำรองการเปลี่ยนแปลงของ Git Branch และเขียนคืนอย่างปลอดภัย
* **รับรู้ Git Repository**: จดจำโฟลเดอร์รูทของไฟล์จาก Git เมื่อสลับกิ่งจะมีการแจ้งเตือนเพื่อให้คลิกเขียนคืนตำแหน่งเดิมได้ทันที
* **ตรวจจับไฟล์ที่ถูกเปิดอยู่**: เรียกใช้ Windows Restart Manager เพื่อตรวจหาไฟล์ที่ถูกเปิดค้างไว้ (เช่น Word, Excel หรือ IDE) ก่อนเขียน ป้องกันไฟล์เสียหาย
* **สแนปช็อตสำรองก่อนเขียนทับ**: มีการสำรองข้อมูลลงใน Blob Store ท้องถิ่นโดยอัตโนมัติก่อนเขียนทับ พร้อมปุ่มเลิกทำคืนค่าได้ในคลิกเดียว
* **ข้ามไฟล์ที่เนื้อหาเหมือนกันด้วยแฮช**: ข้ามการเขียนหากเนื้อหาของไฟล์เหมือนกันทุกไบต์ ช่วยรักษาเวลาแก้ไขดั้งเดิมและป้องกันการบิลด์โดยไม่จำเป็น

### โต๊ะทำงานเต็มรูปแบบ
* **มุมมอง 4 รูปแบบ**: โครงสร้างแบบต้นไม้, รายการแบบแบน, จัดกลุ่มตามโฟลเดอร์ต้นทาง และแบบไอคอนขนาดใหญ่ พร้อมจำรูปแบบที่เลือกไว้
* **โหมดการเขียนคืนที่ยืดหยุ่น**: เขียนคืนตำแหน่งเดิม, โฟลเดอร์ที่ระบุ หรือแมปรูทใหม่ โดยเลือกได้ทั้งแบบโครงสร้างเต็ม, เฉพาะชื่อไฟล์ หรือรวมไฟล์ทั้งหมด
* **ดูตัวอย่างความขัดแย้งล่วงหน้า**: ดูรายละเอียดการเขียนก่อนกดยืนยัน พร้อมตัวเลือก: ถาม, เขียนทับ, ข้าม หรือเปลี่ยนชื่อให้อัตโนมัติ
* **ประวัติการทำงานเป็นชุด**: บันทึกบันทึกการทำงานอย่างละเอียด หากเกิดข้อผิดพลาดบางส่วน สามารถเลือกทำซ้ำเฉพาะรายการที่ไม่สำเร็จได้

### รองรับ 18 ภาษาและธีมระบบ
* รองรับ 18 ภาษาอย่างเป็นทางการ (ผ่านการทดสอบคีย์ตรงกัน 100%) พร้อมการจัดหน้าแบบสะท้อนกลับ (RTL) สำหรับภาษาอาหรับ (ar-SA)
* เข้ากับธีมมืดและสว่างของ Windows ได้อย่างลงตัวด้วยโทนสีกราไฟต์ที่เป็นกลาง

## ปุ่มลัดที่ใช้บ่อย

| ปุ่มลัด | ขอบเขต | รายละเอียด |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | ทั่วทั้งระบบ | เรียกเชลฟ์ขนาดกะทัดรัด หากเลือกไฟล์ใน Explorer อยู่จะนำไฟล์ลงเชลฟ์ทันที |
| <kbd>Win+Alt+W</kbd> | ทั่วทั้งระบบ | เรียกโต๊ะทำงานเต็มรูปแบบ |
| <kbd>Win+Alt+V</kbd> | ทั่วทั้งระบบ | นำไฟล์ในคลิปบอร์ดเข้าสู่เชลฟ์โดยตรง |
| <kbd>Ctrl+V</kbd> | ในหน้าต่าง | วางไฟล์จากคลิปบอร์ดลงในเชลฟ์ที่กำลังเปิดอยู่ |
| <kbd>Ctrl+Shift+N</kbd> | ในหน้าต่าง | สร้างเชลฟ์ชั่วคราวว่างเปล่าอันใหม่ |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | ในหน้าต่าง | สลับระหว่างเชลฟ์ขนาดกะทัดรัดและโต๊ะทำงาน |
| <kbd>Esc</kbd> | ในหน้าต่าง | ในโต๊ะทำงานจะยุบเป็นเชลฟ์ ในเชลฟ์จะซ่อนลงถาดระบบ |
| <kbd>Delete</kbd> | ในรายการ | ลบรายการที่เลือกออกจากเชลฟ์ |

> [!TIP]
> ปุ่มลัดส่วนกลางทั้งหมดสามารถเปลี่ยนหรือปิดใช้งานได้ในการตั้งค่า หากเกิดการชนกับโปรแกรมอื่น StashBay จะแจ้งเตือนอย่างชัดเจน

## พารามิเตอร์คอมมานด์ไลน์ (CLI)

`StashBay.exe` มีพารามิเตอร์คอมมานด์ไลน์สำหรับการเชื่อมต่อกับสคริปต์หรือเครื่องมือภายนอก:

| คำสั่ง | รายละเอียด |
| :--- | :--- |
| `--add <พาธ...>` | เพิ่มไฟล์หรือโฟลเดอร์ลงในเชลฟ์ |
| `--group <ชื่อ>` | ใช้ร่วมกับ `--add` เพื่อระบุเชลฟ์ปลายทาง (จะสร้างให้หากยังไม่มี) |
| `--apply-here <โฟลเดอร์>` | นำไฟล์จากเชลฟ์ไปเขียนลงในโฟลเดอร์ที่ระบุ |
| `--apply-original` | เขียนไฟล์คืนตามพาธสัมพัทธ์เดิม (เหมาะสำหรับ Git) |
| `--show` | แสดงหน้าต่างหลักขึ้นมาด้านหน้า |
| `--minimized` | เริ่มต้นแบบย่อลงในถาดระบบ (สำหรับการเปิดอัตโนมัติพร้อม Windows) |
| `--quit` | ปิดโปรแกรมที่กำลังทำงานอยู่อย่างปลอดภัย |
| `--unregister-shell` | ลบเมนูคลิกขวา ทางลัด Send To และการเปิดอัตโนมัติพร้อมเครื่อง |

## ข้อจำกัดที่ทราบ

* **สร้างขึ้นสำหรับ Windows เท่านั้น**: ผสานการทำงานอย่างลึกซึ้งกับ Windows Shell, DWM และระบบความปลอดภัย ไม่มีแผนพัฒนาสำหรับระบบอื่น
* **สแนปช็อตแทนชอร์ตคัต**: มีการคัดลอกเนื้อหาไฟล์ทันทีที่นำเข้า การแก้ไขไฟล์ต้นฉบับในภายหลังจะไม่มีผลกับไฟล์ในเชลฟ์
* **ทำงานแบบ Single Instance**: การเปิดซ้ำจะส่งพารามิเตอร์ไปยังโพรเซสที่เปิดอยู่ในถาดระบบโดยตรง ไม่สร้างโพรเซสซ้ำซ้อน
* **การเปิดพร้อมเครื่องแบบผู้ดูแลระบบ**: ทำงานด้วยสิทธิ์ปกติ หากต้องลากไฟล์ลงในหน้าต่างที่ใช้สิทธิ์แอดมิน ให้เปิดตัวเลือกผู้ดูแลระบบในการตั้งค่าและยืนยัน UAC [คู่มือการตั้งค่าการเริ่มระบบ](../admin-startup.md)
