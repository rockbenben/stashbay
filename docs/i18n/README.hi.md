# StashBay

> विंडोज़ के बीच फ़ाइलों को आसानी से स्थानांतरित करने के लिए एक हल्का शेल्फ़: फ़ाइलें अंदर छोड़ें, बाहर खींचें और काम पूरा — दो विंडो को अगल-बगल रखने की कोई आवश्यकता नहीं।

Windows डेस्कटॉप के लिए एक हल्का स्थानीय फ़ाइल ट्रांज़िट स्टेशन। यह पूरी तरह से ऑफ़लाइन काम करता है, बिना किसी क्लाउड अपलोड, नेटवर्क अनुरोध या खाता बनाए। इसका उपयोग तुरंत काम निपटाकर बंद करने वाले न्यूनतम शेल्फ़ के रूप में या स्नैपशॉट बैकअप और वन-क्लिक अनडू वाले पूर्ण वर्कबेंच के रूप में किया जा सकता है।

## समर्थित विवरण

| पहलू | समर्थित विनिर्देश |
| :--- | :--- |
| **ऑपरेटिंग सिस्टम** | Windows 10 (1809+) / Windows 11 (x64 और ARM64 के लिए मूल समर्थन) |
| **निर्भरता** | आधिकारिक इंस्टॉलर और पोर्टेबल संस्करणों में रनटाइम शामिल है; स्लिम बिल्ड के लिए .NET 10 Desktop Runtime आवश्यक है |
| **समर्थित डेटा** | किसी भी प्रारूप की फ़ाइलें और बहु-स्तरीय फ़ोल्डर (सापेक्ष निर्देशिका संरचना पूरी तरह सुरक्षित रहती है) |
| **इनपुट के तरीके** | फ़ाइल एक्सप्लोरर चयन, क्लिपबोर्ड फ़ाइल सूची, माउस शेक जेस्चर |
| **पुनर्स्थापना लक्ष्य** | स्थानीय डिस्क, नेटवर्क शेयर (UNC / मैप किए गए ड्राइव), Git रिपॉजिटरी |
| **बड़ी फ़ाइलें** | 2GB से बड़ी एकल फ़ाइलों और Windows लंबे पथों (> 260 वर्ण) का समर्थन करता है |
| **अनुमतियां** | डिफ़ॉल्ट रूप से मानक उपयोगकर्ता अधिकारों के साथ चलता है (`%LOCALAPPDATA%\Programs` में स्थापित); वैकल्पिक व्यवस्थापक ऑटो-स्टार्ट |
| **डेटा संग्रहण** | डिफ़ॉल्ट रूप से `%LOCALAPPDATA%\StashBay\` में सहेजा जाता है (पुराने `FileStash` फ़ोल्डर के साथ पूरी तरह संगत) |

## त्वरित शुरुआत

1. **प्रोग्राम डाउनलोड करें**: [Releases](https://github.com/rockbenben/048-stashbay/releases/latest) से इंस्टॉलर `StashBay-vx.y.z-setup.exe` (व्यवस्थापक अनुमति की आवश्यकता नहीं) या पोर्टेबल `StashBay-vx.y.z-win-x64.zip` डाउनलोड करें।
2. **शेल्फ़ खोलें**: शॉर्टकट <kbd>Win+Alt+S</kbd> दबाएं; मिनी शेल्फ़ तुरंत सक्रिय स्क्रीन पर माउस कर्सर के पास खुल जाएगा।
3. **फ़ाइलें रखें**: फ़ाइल एक्सप्लोरर में फ़ाइलों का चयन करें और फिर से <kbd>Win+Alt+S</kbd> दबाएं (या उन्हें शेल्फ़ में खींचें, या माउस हिलाएं) — चयनित फ़ाइलें तुरंत सुरक्षित हो जाएंगी।
4. **एक बार में बाहर खींचें**: शेल्फ़ के नीचे स्थित `[⤹ कुल X आइटम]` हैंडल को पकड़ें और एक ही इशारे में सभी फ़ाइलों को लक्षित विंडो या चैट ऐप में खींचें। फ़ाइलें खाली होते ही शेल्फ़ स्वचालित रूप से बंद हो जाता है।

## मुख्य विशेषताएं

### न्यूनतम ट्रांज़िट शेल्फ़ (DropPoint अनुभव)
* **एक इशारे में बल्क एक्सपोर्ट**: एक्सप्लोरर, मैसेजिंग ऐप या वेब फ़ॉर्म में सभी फ़ाइलों को एक साथ ले जाने के लिए नीचे दिए गए काउंटर हैंडल को खींचें।
* **खाली होने पर स्वतः बंद**: फ़ाइलें सफलतापूर्वक स्थानांतरित होने के बाद शेल्फ़ से हट जाती हैं; खाली होने पर विंडो अपने आप गायब हो जाती है।
* **कर्सर पर सीधे खुलना**: ग्लोबल हॉटकी माउस की स्थिति का पता लगाकर शेल्फ़ को ठीक उसी मॉनिटर पर खोलती है।
* **माउस हिलाकर फ़ाइलें जोड़ना**: एक्सप्लोरर में फ़ाइलें खींचते समय कर्सर को थोड़ा हिलाएं और शेल्फ़ तुरंत खुलकर फ़ाइलें सहेज लेगा।
* **मैग्नेटिक फ्लोटिंग बॉल**: स्क्रीन के किनारे पर एक छोटा बटन जो क्लिक करने पर खुलता है और छोड़ने पर स्क्रीन के किनारे से चिपक जाता है।
* **स्वतंत्र बहु-शेल्फ़**: ट्रे आइकन पर डबल-क्लिक करें या <kbd>Ctrl+Shift+N</kbd> दबाकर नए अस्थायी शेल्फ़ बनाएं; खाली शेल्फ़ अपने आप साफ़ हो जाते हैं।

### Git शाखा बदलावों का बैकअप और सुरक्षित पुनर्स्थापना
* **रिपॉजिटरी पहचान**: Git फ़ाइलों के रूट को पहचानता है; शाखा बदलने पर मूल स्थान पर एक क्लिक में पुनर्स्थापित करने का सुझाव देता है।
* **लिखने से पहले लॉक जांच**: लिखने से पहले Windows रीस्टार्ट मैनेजर के माध्यम से जांच करता है कि फ़ाइल Office या IDE में खुली तो नहीं है।
* **ओवरराइट से पहले सुरक्षित स्नैपशॉट**: किसी भी फ़ाइल को बदलने से पहले स्थानीय ब्लॉब स्टोर में स्वचालित बैकअप बनता है, जिसे एक क्लिक में पूर्ववत किया जा सकता है।
* **हैश तुलना द्वारा डुप्लिकेट छोड़ना**: सामग्री समान होने पर पुनः लिखने से बचता है, जिससे मूल संशोधन समय सुरक्षित रहता है।

### संपूर्ण वर्कबेंच
* **चार दृश्य मोड**: ट्री व्यू, फ्लैट लिस्ट, स्रोत फ़ोल्डर अनुसार समूहीकरण और बड़े आइकन टाइल्स।
* **लचीले पुनर्स्थापना मोड**: मूल स्थान, विशिष्ट निर्देशिका या नया रूट; पूर्ण पथ, केवल नाम या फ्लैट संरचना का विकल्प।
* **टकराव का पूर्वावलोकन**: लागू करने से पहले विस्तृत पूर्वावलोकन देखें: पूछें, ओवरराइट करें, छोड़ें या स्वतः नाम बदलें।
* **बैच संचालन इतिहास**: प्रत्येक पुनर्स्थापना का विस्तृत लॉग; आंशिक विफलता होने पर केवल विफल फ़ाइलों को पुनः आज़माएं।

### 18 मूल भाषाएं और थीम
* 18 भाषाओं के लिए आधिकारिक समर्थन (परीक्षणों द्वारा 100% सत्यापित) और अरबी (ar-SA) के लिए पूर्ण RTL समर्थन।
* तटस्थ ग्रेफाइट टोन के साथ Windows के डार्क और लाइट मोड का सहज समर्थन।

## अक्सर इस्तेमाल होने वाले शॉर्टकट

| शॉर्टकट | दायरा | विवरण |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | ग्लोबल | मिनी शेल्फ़ खोलें; यदि एक्सप्लोरर में फ़ाइलें चुनी हैं, तो उन्हें तुरंत जोड़ेगा |
| <kbd>Win+Alt+W</kbd> | ग्लोबल | संपूर्ण वर्कबेंच खोलें |
| <kbd>Win+Alt+V</kbd> | ग्लोबल | क्लिपबोर्ड की फ़ाइलों को सीधे शेल्फ़ में जोड़ें |
| <kbd>Ctrl+V</kbd> | विंडो में | क्लिपबोर्ड फ़ाइलों को सक्रिय शेल्फ़ में चिपकाएं |
| <kbd>Ctrl+Shift+N</kbd> | विंडो में | एक नया स्वतंत्र खाली शेल्फ़ बनाएं |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | विंडो में | मिनी शेल्फ़ और पूर्ण वर्कबेंच के बीच स्विच करें |
| <kbd>Esc</kbd> | विंडो में | वर्कबेंच में शेल्फ़ में समेटें; शेल्फ़ में ट्रे में छिपाएं |
| <kbd>Delete</kbd> | सूची | चयनित फ़ाइलों को शेल्फ़ से हटाएं |

> [!TIP]
> सभी ग्लोबल शॉर्टकट सेटिंग्स में बदले या बंद किए जा सकते हैं। यदि कोई शॉर्टकट किसी अन्य प्रोग्राम से टकराता है, तो StashBay स्पष्ट चेतावनी देगा।

## कमांड-लाइन इंटरफ़ेस (CLI)

`StashBay.exe` स्क्रिप्ट और बाहरी टूल्स के साथ एकीकरण के लिए समृद्ध कमांड-लाइन विकल्प प्रदान करता है:

| विकल्प | विवरण |
| :--- | :--- |
| `--add <पथ...>` | एक या अधिक फ़ाइलें/फ़ोल्डर शेल्फ़ में जोड़ें |
| `--group <नाम>` | लक्षित शेल्फ़ निर्दिष्ट करने के लिए `--add` के साथ प्रयोग करें (यदि नहीं है तो बन जाएगा) |
| `--apply-here <फ़ोल्डर>` | शेल्फ़ की फ़ाइलों को निर्दिष्ट फ़ोल्डर में लिखें |
| `--apply-original` | फ़ाइलों को उनके मूल सापेक्ष पथ पर पुनर्स्थापित करें (Git के लिए उपयुक्त) |
| `--show` | मुख्य विंडो को सामने लाएं और प्रदर्शित करें |
| `--minimized` | सिस्टम ट्रे में छोटा करके प्रारंभ करें (Windows ऑटो-स्टार्ट के लिए) |
| `--quit` | चल रहे इंस्टेंस को सुरक्षित रूप से बंद करें |
| `--unregister-shell` | राइट-क्लिक मेनू, सेंड-टू शॉर्टकट और ऑटो-स्टार्ट हटाएं |

## ज्ञात सीमाएं

* **केवल Windows के लिए**: Windows Shell, DWM और सुरक्षा नियंत्रणों के साथ गहराई से एकीकृत; अन्य OS के लिए कोई योजना नहीं है।
* **लिंक के बजाय स्नैपशॉट**: फ़ाइलें जोड़ते समय सामग्री की प्रतिलिपि बनाई जाती है; मूल फ़ाइलों में बदलाव से शेल्फ़ प्रभावित नहीं होता।
* **एकल इंस्टेंस तंत्र**: ऐप को फिर से चलाने पर पैरामीटर ट्रे में पहले से चल रही प्रक्रिया को भेज दिए जाते हैं।
* **व्यवस्थापक ऑटो-स्टार्ट नोट**: डिफ़ॉल्ट रूप से सामान्य अनुमतियों के साथ चलता है। यदि व्यवस्थापक विंडो में फ़ाइलें खींचने की आवश्यकता है, तो सेटिंग्स में व्यवस्थापक ऑटो-स्टार्ट चालू करें और UAC स्वीकृत करें। [ऑटो-स्टार्ट सेटअप गाइड](../admin-startup.md)।
