# StashBay

> رف مصغر لنقل الملفات بين النوافذ بكل سلاسة: اسحب الملفات وضعها جانباً، ثم اسحبها إلى وجهتها وانتهى الأمر — دون الحاجة لترتيب النوافذ جنباً إلى جنب.

محطة ترانزيت محلية خفيفة لنقل الملفات على سطح مكتب Windows. تعمل بالكامل محلياً دون رفع إلى السحابة، دون اتصالات شبكية، ودون الحاجة لتسجيل حساب. تعمل كرف مؤقت للاستخدام السريع والإنهاء الفوري، أو كمنصة عمل متكاملة للملفات مع دعم مستودعات Git، والنسخ الاحتياطي عبر اللقطات، والتراجع بنقرة واحدة.

---

## نطاق الدعم

| الجانب | المواصفات المدعومة |
| :--- | :--- |
| **نظام التشغيل** | Windows 10 (1809+) / Windows 11 (دعم أصلي لمعماريات x64 و ARM64) |
| **متطلبات التشغيل** | يتضمن مثبت الحزمة والإصدار المحمول الرسمي بيئة التشغيل بالكامل؛ تتطلب الحزم المصغرة بيئة .NET 10 Desktop Runtime |
| **الملفات المدعومة** | ملفات بجميع التنسيقات ومجلدات متعددة المستويات (مع الحفاظ الكامل على الهيكل النسبي) |
| **طرق الإدخال** | تحديد متعدد في مستكشف الملفات، قائمة ملفات الحافظة، إيماءة هز مؤشر الفأرة |
| **وجهات الاستعادة** | الأقراص المحلية، المشاركات الشبكية (UNC / محركات الأقراص المعينة)، مستودعات Git |
| **الملفات الكبيرة** | دعم الملفات الفردية التي يتجاوز حجمها 2 جيجابايت، ودعم مسارات Windows الطويلة (> 260 حرفاً) |
| **الصلاحيات** | يعمل بصلاحيات المستخدم العادية افتراضياً (مثبت في `%LOCALAPPDATA%\Programs`)؛ تشغيل تلقائي اختياري كمسؤول |
| **موقع البيانات** | يُحفظ افتراضياً في `%LOCALAPPDATA%\StashBay\` (متوافق تلقائياً مع مجلد `FileStash` القديم) |

## البدء السريع

1. **تحميل البرنامج**: نزّل مثبت `StashBay-vx.y.z-setup.exe` (لا يتطلب صلاحيات مسؤول) أو الحزمة المحمولة `StashBay-vx.y.z-win-x64.zip` من صفحة [Releases](https://github.com/rockbenben/stashbay/releases/latest).
2. **استدعاء الرف**: اضغط على الاختصار <kbd>Win+Alt+S</kbd> ليفتح الرف المصغر فوراً بجوار مؤشر الفأرة على الشاشة النشطة.
3. **وضع الملفات**: حدد الملفات في مستكشف الملفات واضغط على <kbd>Win+Alt+S</kbd> مجدداً (أو اسحبها نحو الرف، أو هز الفأرة) لتوضع في الرف على الفور.
4. **السحب والإفلات دفعة واحدة**: اسحب مقبض `[⤹ الإجمالي X عناصر]` أسفل الرف لنقل جميع الملفات بحركة واحدة نحو النافذة المستهدفة أو التطبيق. عند إفراغ الرف، يختفي تلقائياً بهدوء.

## الميزات الرئيسية

### رف نقل مبسط (تجربة DropPoint)
* **تصدير دفعي بحركة واحدة**: اسحب مقبض العداد لنقل كافة الملفات دفعة واحدة إلى مستكشف الملفات أو برامج المحادثة أو نماذج الويب.
* **إغلاق تلقائي عند الإفراغ**: يتم استبعاد الملفات من الرف بمجرد وصولها بنجاح إلى وجهتها، وتتلاشى النافذة تلقائياً عند تفريغها بالكامل.
* **الظهور عند موضع المؤشر**: يكتشف الاختصار العام الشاشة التي يوجد عليها مؤشر الفأرة ليفتح الرف هناك فوراً.
* **هز الفأرة للحفظ**: أثناء سحب الملفات في المستكشف، هز المؤشر يميناً ويساراً لفتح الرف وحفظ الملفات في مكانها.
* **كرة عائمة مغناطيسية**: زر صغير على حافة الشاشة يتوسع بنقرة أو سحبة خفيفة ويلتصق مغناطيسياً بحافة الشاشة عند الإفلات.
* **رفوف متعددة مستقلة**: انقر نقراً مزدوجاً على أيقونة شريط المهام أو اضغط <kbd>Ctrl+Shift+N</kbd> لإنشاء رف مؤقت مستقل؛ ويتم تنظيف الرفوف المؤقتة الفارغة تلقائياً.

### حفظ تعديلات فروع Git واستعادتها بأمان
* **إدراك ذكي للمستودع**: يتعرف على جذر المستودع للملفات المحفوظة؛ وعند التبديل بين الفروع، يظهر إشعار يتيح استعادتها إلى موضعها الأصلي بنقرة واحدة.
* **فحص الملفات المقفلة قبل الكتابة**: يستخدم مدير إعادة تشغيل Windows للتحقق من الملفات المفتوحة (في برامج Office أو IDEs) قبل الكتابة لتفادي التلف.
* **لقطات أمان قبل الاستبدال**: يتم إنشاء نسخة احتياطية تلقائياً في مخزن محلي قبل الكتابة فوق أي ملف، مع إمكانية التراجع الفوري بنقرة واحدة.
* **تخطي الملفات المتطابقة عبر التجزئة**: يتخطى الكتابة إذا كانت المحتويات متطابقة تماماً، للحفاظ على وقت التعديل الأصلي وتجنب إعادة البناء غير الضرورية.

### منصة عمل كاملة
* **أربعة أوضاع للعرض**: عرض شجري، قائمة بسيطة، تجميع حسب المجلد المصدر، وبلاطات بأيقونات كبيرة، مع حفظ حالة العرض.
* **أوضاع استعادة مرنة**: الاستعادة في الموضع الأصلي، أو في مجلد محدد، أو تعيين جذر جديد؛ بهيكل المسار النسبي الكامل، أو اسم الملف فقط، أو تسطيح المجلدات.
* **معاينة مسبقة للتضارب**: مراجعة دقيقة للإجراءات قبل التنفيذ، مع خيارات: السؤال، الاستبدال، التخطي، أو إعادة التسمية التلقائية.
* **سجل العمليات الدفعية**: تسجيل مفصل لكل عملية استعادة؛ في حال حدوث خطأ جزئي، يمكنك إعادة محاولة العناصر الفاشلة فقط.

### دعم أصلي لـ 18 لغة ومظهر مخصص
* دعم أصلي متكامل لـ 18 لغة مع تطابق مفاتيح بنسبة 100% تم التحقق منها عبر الاختبارات، مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL) للغة العربية (ar-SA).
* توافق تام مع وضعي Windows الداكن والفاتح بدرجات الجرافيت المحايدة.

## اختصارات لوحة المفاتيح الشائعة

| الاختصار | النطاق | الوصف |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | عام | فتح الرف المصغر؛ إذا كان المستكشف نشطاً وبه ملفات محددة، تُضاف فوراً |
| <kbd>Win+Alt+W</kbd> | عام | فتح منصة العمل الكاملة |
| <kbd>Win+Alt+V</kbd> | عام | إضافة الملفات الموجودة في الحافظة مباشرة إلى الرف |
| <kbd>Ctrl+V</kbd> | داخل النافذة | لصق ملفات الحافظة في الرف النشط |
| <kbd>Ctrl+Shift+N</kbd> | داخل النافذة | إنشاء رف مؤقت فارغ جديد ومستقل |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | داخل النافذة | التبديل بسلاسة بين الرف المصغر ومنصة العمل الكاملة |
| <kbd>Esc</kbd> | داخل النافذة | في منصة العمل يتقلص إلى الرف؛ وفي الرف يختفي إلى شريط المهام |
| <kbd>Delete</kbd> | القائمة | إزالة العناصر المحددة من الرف |

> [!TIP]
> يمكن تعديل الاختصارات العامة أو تعطيلها في الإعدادات؛ وإذا تعارض اختصار مع برنامج آخر، سيظهر لك تنبيه صريح بالتعارض.

## واجهة سطر الأوامر (CLI)

يوفر `StashBay.exe` واجهة سطر أوامر غنية للتكامل مع المشغلات الخارجية والسكربتات وسير العمل الآلي:

| المعامل | الوصف |
| :--- | :--- |
| `--add <مسارات...>` | إضافة ملف أو أكثر أو مجلدات إلى الرف |
| `--group <اسم>` | يُستخدم مع `--add` لتحديد الرف المستهدف (يُنشأ إذا لم يكن موجوداً) |
| `--apply-here <مجلد>` | كتابة ملفات الرف في المجلد المحدد |
| `--apply-original` | استعادة الملفات في مساراتها النسبية الأصلية (مثالي لـ Git) |
| `--show` | إظهار النافذة الرئيسية في المقدمة |
| `--minimized` | بدء التشغيل مصغراً في شريط المهام (لبدء التشغيل التلقائي مع النظام) |
| `--quit` | إنهاء الجلسة قيد التشغيل بأمان |
| `--unregister-shell` | إلغاء تسجيل عناصر قائمة السياق، واختصار الإرسال إلى، وبدء التشغيل التلقائي |

## القيود المعروفة

* **خاص بنظام Windows**: متكامل بعمق مع واجهة Windows Shell ومعالجة DWM وإدارة الوصول؛ ولا توجد خطط لإصدارات لأنظمة أخرى.
* **لقطات محتوى وليست اختصارات**: يتم نسخ المحتوى كلقطة مستقلة عند الإضافة؛ التعديلات اللاحقة على الملفات الأصلية لا تغير محتويات الرف.
* **تشغيل نسخة واحدة**: إعادة تشغيل البرنامج تمرر المعاملات إلى العملية الرئيسية النشطة في شريط المهام دون تكرار العمليات في الخلفية.
* **بدء التشغيل التلقائي كمسؤول**: يعمل افتراضياً بصلاحيات المستخدم العادية. إذا كنت بحاجة لسحب ملفات إلى نوافذ تتطلب صلاحيات مرتفعة، فعّل بدء التشغيل كمسؤول في الإعدادات ووافق على مطالبة UAC. [دليل إعداد بدء التشغيل](../admin-startup.md).
