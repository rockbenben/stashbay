# StashBay

> 창 사이로 파일을 옮길 때 사용하는 초경량 임시 선반: 드래그해서 넣어두고, 끌어다 쓰고 끝 — 창을 나란히 띄워둘 필요가 없습니다.

Windows 데스크톱용 초경량 파일 중계 스테이션입니다. 모든 작업이 로컬에서 처리되며, 외부 업로드, 네트워크 연결, 계정 가입이 전혀 필요하지 않습니다. 간편하게 쓰고 닫는 미니멀 선반뿐만 아니라 스냅샷 백업과 원클릭 실행 취소를 지원하는 완전한 파일 워크벤치로도 활용할 수 있습니다.

## 지원 사양

| 항목 | 지원 사양 |
| :--- | :--- |
| **운영체제** | Windows 10 (1809+) / Windows 11 (x64 및 ARM64 기본 지원) |
| **실행 환경** | 공식 설치형 및 포터블 버전은 런타임 내장(압축 해제 또는 실행 시 즉시 사용). 슬림 빌드는 .NET 10 데스크톱 런타임 필요 |
| **보관 대상** | 모든 형식의 파일 및 다층 폴더(상대 경로 디렉터리 계층 완전 유지) |
| **입력 방식** | 파일 탐색기 다중 선택, 클립보드 파일 목록, 마우스 흔들기 제스처 |
| **복원 대상** | 로컬 디스크, 네트워크 공유 경로(UNC / 매핑된 드라이브), Git 저장소 |
| **대용량 파일** | 2GB 초과 대용량 파일 지원, Windows 긴 경로(260자 초과) 지원 |
| **권한 구조** | 기본적으로 일반 사용자 권한으로 실행(`%LOCALAPPDATA%\Programs`에 설치, UAC 불필요). 관리자 자동 시작 선택 가능 |
| **데이터 저장 위치** | 기본 `%LOCALAPPDATA%\StashBay\`에 저장(레거시 `FileStash` 폴더 자동 호환) |

## 빠른 시작

1. **프로그램 다운로드**: [Releases](https://github.com/rockbenben/stashbay/releases/latest)에서 설치형 `StashBay-vx.y.z-setup.exe`(관리자 권한 불필요) 또는 무설치 포터블 `StashBay-vx.y.z-win-x64.zip`을 다운로드합니다.
2. **선반 호출**: 단축키 <kbd>Win+Alt+S</kbd>를 누르면 현재 마우스 커서가 위치한 화면에 미니 선반이 즉시 열립니다.
3. **파일 보관**: 탐색기에서 파일을 선택하고 <kbd>Win+Alt+S</kbd>를 다시 누르면(또는 선반으로 드래그하거나 마우스를 흔들면) 선택한 파일이 선반에 담깁니다.
4. **일괄 드래그 아웃**: 선반 하단의 `[⤹ 총 X개 항목]` 핸들을 잡고 드래그하면 한 번의 제스처로 모든 파일을 대상 창이나 메신저로 내보낼 수 있습니다. 모든 파일이 비워지면 선반이 자동으로 페이드아웃되며 닫힙니다.

## 핵심 기능

### 미니멀 파일 보관함 (DropPoint 스타일)
* **원샷 일괄 드래그**: 하단 카운트 핸들을 끌어 모든 보관 파일을 파일 탐색기, 슬랙, 디스코드, 웹 브라우저 양식으로 한 번에 보낼 수 있습니다.
* **비우면 자동 닫힘**: 대상 폴더로 파일이 성공적으로 옮겨지면 목록에서 제외되며, 선반이 완전히 비워지면 창이 매끄럽게 사라집니다.
* **커서 위치 추종 호출**: 단축키 실행 시 마우스가 있는 모니터로 창이 자동으로 배치되어 모니터를 넘나들며 창을 찾을 필요가 없습니다.
* **마우스 흔들어 담기**: 파일 드래그 도중 커서를 좌우로 가볍게 흔들면 그 자리에서 선반이 펼쳐지며 파일이 자동 보관됩니다.
* **화면 가장자리 플로팅 볼**: 화면 테두리에 붙어 있는 작은 버튼으로, 클릭하거나 살짝 끌면 선반이 열리고 놓으면 가장자리에 자석처럼 달라붙습니다.
* **독립 다중 보관함**: 트레이 아이콘을 더블 클릭하거나 <kbd>Ctrl+Shift+N</kbd>을 눌러 독립된 임시 보관함을 추가할 수 있으며, 비워진 임시 보관함은 자동으로 정리됩니다.

### Git 브랜치 변경사항 보관 및 안전한 복원
* **저장소 자동 인식**: 보관된 파일이 Git 저장소에 속한 경우 루트 디렉터리를 감지합니다. 브랜치 전환 시 알림이 표시되며 클릭 한 번으로 원래 위치에 복원할 수 있습니다.
* **쓰기 전 잠금 감지**: 파일을 덮어쓰기 전에 Windows 재시작 관리자를 호출하여 Office나 IDE 등의 파일 잠금을 사전에 감지하고 불완전한 덮어쓰기를 방지합니다.
* **안전한 스냅샷 백업**: 파일 덮어쓰기 전 로컬 Blob 저장소에 자동 스냅샷을 생성하여 언제든 원클릭으로 실행 취소할 수 있습니다.
* **해시 기반 중복 건너뛰기**: 내용이 완전히 같은 파일은 쓰기를 건너뛰고 기존 수정 시간을 유지하여 불필요한 빌드나 핫 리로드를 방지합니다.

### 전체 워크벤치
* **다양한 보기 모드**: 트리 계층형, 플랫 리스트, 원본 폴더별 그룹화, 대형 아이콘 타일 등 4가지 보기를 제공하며 상태가 저장됩니다.
* **유연한 복원 방식**: 원래 위치 복원, 대상 디렉터리 지정, 새 루트 매핑을 지원하며 전체 상대 경로, 파일명 전용, 전체 플랫 구조를 선택할 수 있습니다.
* **충돌 사전 미리보기**: 적용 전 파일 목록을 미리 확인하고 묻기, 덮어쓰기, 건너뛰기, 자동 이름 변경 등의 충돌 처리 정책을 선택할 수 있습니다.
* **배치 작업 내역**: 모든 복원 작업에 대해 상세 로그와 결과를 기록하며, 일부 항목이 실패한 경우 실패한 항목만 다시 시도할 수 있습니다.

### 18개 언어 기본 지원 및 테마
* 18개 언어 공식 지원(자동화 테스트를 통해 100% 키 일치 보장) 및 아랍어(ar-SA) RTL 미러링 완벽 지원.
* Windows 다크 및 라이트 모드에 자연스럽게 어울리는 중립 흑연(Graphite) 색상 적용.

## 자주 사용하는 단축키

| 단축키 | 적용 범위 | 기능 설명 |
| :--- | :--- | :--- |
| <kbd>Win+Alt+S</kbd> | 전역 | 미니 선반 열기. 파일 탐색기에서 선택된 파일이 있으면 즉시 선반에 보관 |
| <kbd>Win+Alt+W</kbd> | 전역 | 전체 워크벤치 열기 |
| <kbd>Win+Alt+V</kbd> | 전역 | 클립보드에 복사된 파일을 선반에 즉시 추가 |
| <kbd>Ctrl+V</kbd> | 창 내부 | 클립보드 파일을 현재 보관함에 붙여넣기 |
| <kbd>Ctrl+Shift+N</kbd> | 창 내부 | 새로운 독립 빈 보관함 생성 |
| <kbd>F11</kbd> / <kbd>Ctrl+E</kbd> | 창 내부 | 미니 선반과 전체 워크벤치 모드 전환 |
| <kbd>Esc</kbd> | 창 내부 | 워크벤치 모드에서는 선반으로 축소, 선반 모드에서는 트레이로 숨김 |
| <kbd>Delete</kbd> | 목록 | 선택한 보관 파일 제거 |

> [!TIP]
> 전역 단축키는 설정에서 변경하거나 비활성화할 수 있습니다. 다른 프로그램과 단축키가 충돌하면 조용히 실패하지 않고 명확한 안내를 표시합니다.

## 명령줄 인터페이스 (CLI)

`StashBay.exe`는 외부 런처나 자동화 스크립트 연동을 위한 명령줄 인터페이스를 제공합니다:

| 매개변수 | 설명 |
| :--- | :--- |
| `--add <경로...>` | 지정한 파일 또는 폴더를 보관함에 추가 |
| `--group <그룹명>` | `--add`와 함께 사용하여 대상 보관함 지정(없으면 자동 생성) |
| `--apply-here <경로>` | 보관함의 파일을 지정한 디렉터리로 복원 |
| `--apply-original` | 상대 경로를 유지한 채 원래 위치로 복원(Git 브랜치 복원에 적합) |
| `--show` | 메인 창 열기 및 표시 |
| `--minimized` | 트레이에 최소화 상태로 실행(Windows 시작 프로그램용) |
| `--quit` | 실행 중인 인스턴스 안전 종료 |
| `--unregister-shell` | 우클릭 메뉴, 보내기 바로가기, 시작 프로그램 등록 해제 |

## 알려진 제한 사항

* **Windows 전용**: Windows Shell, DWM 믹스 렌더링, 보안 제어와 깊이 통합되어 Windows 환경만 지원합니다.
* **스냅샷 복사 방식**: 보관 시 실제 파일 내용을 즉시 스냅샷으로 복사하므로 원본 파일을 수정하거나 삭제해도 보관함 내용은 변경되지 않습니다.
* **단일 인스턴스 구조**: 중복 실행 시 이미 트레이에서 실행 중인 프로세스로 인수를 자동 전달하여 불필요한 백그라운드 프로세스가 남지 않습니다.
* **관리자 권한 자동 시작**: 기본적으로 일반 사용자 권한으로 실행됩니다. 관리자 권한 창으로 파일을 드래그해야 하는 경우 설정에서 관리자 권한 자동 시작을 켜고 등록 시 UAC 승인을 진행하세요. [자동 시작 설정 안내](../admin-startup.md).
